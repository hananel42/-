# Binary Files Storage Repository

This repository is intended for storing my personal binary files.

Anyone can use these files if they want, but it is **strongly discouraged** to download and run binary files when you do not know exactly what they do—especially from repositories owned by people you do not know.

## Intended Personal Usage

This repository is mainly for my own quick-install workflow, for example:

```powershell
irm https://raw.githubusercontent.com/myusername/-/main/myapp | iex
```

That lets me upload binaries here and fetch related installer scripts from any machine with a single command.

## Safety Note

Always inspect scripts and verify the source and file integrity before running anything.
